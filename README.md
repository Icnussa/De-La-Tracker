# DE LA TRACKER

A school calendar app: assessments, events, a homework diary, grades and term dates.

Live at https://icnussa.github.io/de-la-tracker/

Everything you add is saved on your own device (in the browser), not in this repository.
Use **Back up** (colour button, top right) to save a copy of your data, and **Restore** to load it on another device.

To install on iPhone: open the link in Safari, tap Share, then **Add to Home Screen**.
